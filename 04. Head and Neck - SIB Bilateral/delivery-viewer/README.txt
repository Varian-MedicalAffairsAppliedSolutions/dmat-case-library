Lightweight viewer: dose grid and accumulation caches omitted; accumulation disabled.

Delivery Studio packaged case

Illustrative only. The machine visualization is based on publicly available data and does not represent actual machine specifications or dimensions.

Unzip and open index.html in a modern WebGL2 browser, or serve this folder with any static web server. No backend or external libraries are required. Press Play to run all fields using the included camera keys.

To embed after hosting this folder:
<iframe src="case-demo/index.html" width="100%" height="850" title="Delivery case demo" style="border:0"></iframe>

Includes processed case anatomy, delivery data, optional dose and camera keyframes. Original DICOM files are not included. Case labels and anatomical data remain in this package.
