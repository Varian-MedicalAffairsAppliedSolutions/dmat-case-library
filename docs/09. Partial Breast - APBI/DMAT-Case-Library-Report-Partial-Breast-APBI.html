Colorwash sampling details

Every dose is evaluated on DA277’s patient-coordinate dose grid before CT slices are sampled every 5 mm from its isocenter. Native grids that differ are trilinearly resampled. The in-plane display and superior–inferior slice range are restricted to the selected reference plan’s 40% prescription-dose bounding volume plus 50 mm in every direction; CT slices outside that range are not embedded. Each colorwash has a slim slice slider beneath it; moving any slider advances every plan synchronously. Scroll over an image or use arrow keys to change slices. Dragging is disabled. Centered zoom (+/−) and reset (0 or double-click) remain synchronized. All plans use the confirmed 5–32.5 Gy color scale.
